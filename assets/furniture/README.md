# Furniture pictures

Put top-down (bird's-eye) PNG pictures here, one per furniture type, with a
transparent background and the back of the piece at the top of the image:

bed.png, sofa.png, table.png, chair.png, wardrobe.png, tv.png, plant.png,
storage.png, desk.png, bookshelf.png, rug.png, lamp.png, mirror.png

The app uses a picture when it exists and the drawn version otherwise.
Use images you have the right to ship (your own renders or a licensed pack).
